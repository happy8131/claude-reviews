# Notion 기반 견적서 웹 뷰어 MVP PRD

## 🎯 핵심 정보

**목적**: 영업 담당자가 Notion에 입력한 견적서를, 클라이언트가 별도 로그인 없이 웹에서 확인하고 PDF로 저장할 수 있게 한다.
**사용자**: 영업 담당자로부터 견적서 공개 링크를 전달받은 B2B 클라이언트(구매 담당자, 의사결정권자).

## 🚶 사용자 여정

```
1. [견적서 공개 링크 접속] (영업 담당자가 공유한 링크)
   ↓ Notion API로 견적서 ID 조회

2. [견적서 상세 페이지] 로딩
   ↓ 조회 결과 분기

   [조회 성공] → 견적서 요약 정보 + 항목 리스트 렌더링
   [조회 실패 / 존재하지 않음 / 비공개·만료] → 오류 안내 페이지로 자동 전환
   ↓

3. [견적서 상세 페이지]에서 내용 확인
   ↓ "PDF 다운로드" 버튼 클릭

4. [PDF 생성] → 완료 → 파일 다운로드
```

## ⚡ 기능 명세

### 1. MVP 핵심 기능

| ID | 기능명 | 설명 | MVP 필수 이유 | 관련 페이지 |
|----|--------|------|-------------|------------|
| **F001** | 견적서 조회 | Notion Quotes DB에서 견적서 단건 데이터 조회 (Notion API) | 서비스의 존재 이유 자체 | 견적서 상세 페이지 |
| **F002** | 견적 항목 렌더링 | Notion Items DB에서 견적서와 연결된 항목(품목, 수량, 단가, 설명) 조회 및 리스트 표시 | 견적 내용의 핵심 구성요소 | 견적서 상세 페이지 |
| **F003** | 견적서 요약 표시 | 고객명, 총 금액, 유효기한, 상태, 비고를 요약 영역에 표시 | 클라이언트가 한눈에 파악해야 할 핵심 정보 | 견적서 상세 페이지 |
| **F004** | PDF 다운로드 | 화면에 렌더링된 견적서를 PDF 파일로 변환하여 다운로드 | 오프라인 보관/내부 결재용 필수 요구사항 | 견적서 상세 페이지 |

### 2. MVP 필수 지원 기능

| ID | 기능명 | 설명 | MVP 필수 이유 | 관련 페이지 |
|----|--------|------|-------------|------------|
| **F005** | 반응형 레이아웃 | 모바일/데스크톱 화면 크기에 맞춰 견적서 및 안내 화면 자동 조정 | 클라이언트가 모바일에서도 링크를 열어보는 경우가 많음 | 견적서 상세 페이지, 오류 안내 페이지 |
| **F006** | 조회 실패 안내 | 존재하지 않음/비공개/유효기한 만료 등 조회 실패 사유별 안내 메시지 표시 | 잘못된 링크·만료 링크 접근 시 사용자 혼란 방지 | 오류 안내 페이지 |

### 3. MVP 이후 기능 (제외)

- 영업 담당자용 로그인 및 견적서 관리(작성/수정/삭제) 화면
- 견적서 목록·검색·필터링 페이지
- 견적서 승인/서명/코멘트 기능
- 조회 알림, 열람 이력 등 실시간 알림 기능
- 다국어 지원

## 📱 메뉴 구조

```
📱 Notion 견적서 뷰어 내비게이션
├── 📄 견적서 상세 (공개 링크로 직접 진입, 별도 메뉴 없음)
│    └── 기능: F001, F002, F003, F004, F005 (견적서 조회 및 PDF 다운로드)
```

## 📄 페이지별 상세 기능

### 견적서 상세 페이지

> **구현 기능:** `F001`, `F002`, `F003`, `F004`, `F005` | **메뉴 위치:** 공개 링크 직접 진입 (별도 메뉴 없음)

| 항목 | 내용 |
|------|------|
| **역할** | 클라이언트가 견적 내용을 확인하고 PDF로 저장하는 핵심 뷰어 페이지 |
| **진입 경로** | 영업 담당자가 전달한 견적서 고유 공개 링크로 직접 접속 |
| **사용자 행동** | 견적서 요약(고객명·금액·유효기한·상태·비고)과 항목별 리스트(품목·수량·단가·설명)를 확인하고, 필요 시 PDF로 다운로드 |
| **주요 기능** | • Notion Quotes DB 견적서 단건 조회<br>• Notion Items DB 연결 항목 리스트 조회 및 렌더링<br>• 항목별 소계 및 총 견적 금액 자동 계산 표시<br>• 모바일/데스크톱 반응형 레이아웃<br>• **PDF 다운로드** 버튼 |
| **다음 이동** | 조회 실패 → 오류 안내 페이지로 자동 전환 / PDF 다운로드 클릭 → 페이지 이동 없이 파일 다운로드 |

### 오류 안내 페이지

> **구현 기능:** `F005`, `F006` | **메뉴 위치:** 견적서 조회 실패 시 자동 전환

| 항목 | 내용 |
|------|------|
| **역할** | 유효하지 않은 견적서 링크 접근 시 사유를 안내하는 전용 페이지 |
| **진입 경로** | 견적서 상세 페이지에서 조회 실패(존재하지 않음/비공개/유효기한 만료) 시 자동 전환 |
| **사용자 행동** | 안내 메시지를 확인하고 필요 시 견적서 발신자(영업 담당자)에게 링크 재확인 요청 |
| **주요 기능** | • 오류 유형별 안내 메시지 표시 (견적서 없음 / 유효기한 만료 / 비공개 상태)<br>• 모바일/데스크톱 반응형 레이아웃 |
| **다음 이동** | 없음 (안내 종료 페이지) |

## 🗄️ 데이터 모델

> Notion 데이터베이스를 그대로 소스로 사용하며, 애플리케이션은 별도 DB 없이 Notion API 조회 결과를 읽기 전용으로 매핑한다.

### Quote (견적서, Notion Quotes DB)
| 필드 | 설명 | 타입/관계 |
|------|------|----------|
| id | Notion Page ID | String |
| title | 견적서 제목 | String |
| clientName | 고객명 | String |
| amount | 총 견적 금액 | Number |
| validUntil | 유효기한 | Date |
| notes | 비고/메모 | Text |
| status | 견적서 상태 (공개/비공개/만료 등) | String |

### Item (견적 항목, Notion Items DB)
| 필드 | 설명 | 타입/관계 |
|------|------|----------|
| id | Notion Page ID | String |
| quoteId | 소속 견적서 | → Quote.id |
| name | 품목명 | String |
| qty | 수량 | Number |
| unitPrice | 단가 | Number |
| description | 항목 설명 | Text |
